## Project Title: AD 312 State Management with useImmer Hook
#### By: Amde Wubshet

### Breif Description
 Manage complex, nested React state using the useImmer hook. This tool facilitates easier and more readable state updates by allowing you to "mutate" a proxy state while maintaining the strict immutability required by React.

### Commands 
After installing the repo, navigate into your project directory: *cd user-profile-immer*. Then start the development server: *npm run dev*. When the page loads you should see a series of input fields, followed by two buttons: 
- Update Information: When clicked, the page rerenders the "Current User" with information typed in the input field. 
- Newsletter Notification: A button that changes the boolean of "newsletter" property.
